## 产品是什么

**ShipFire** 是一款 **AI Website Builder**：用户用一句话描述业务，系统生成可编辑的多页网站草稿，再 refine 后发布。

| 项 | 说明 |
|---|---|
| **目标用户** | 需要快速上线官网/落地页的独立开发者、小团队、非技术创始人 |
| **核心价值** | 从空白页到结构化网站草稿，describe → draft → edit → publish |
| **当前形态** | Early Access / Coming Soon：落地页 + 工具区占位，有限免费生成尚未开放 |
| **免费层** | 早期访问阶段：Limited free generations（文案承诺，功能待上线） |
| **付费层** | 更多生成次数、自定义域名、发布扩展（积分或套餐，后续版本） |

## 设计原则（简要）

1. **工具优先**：首屏让用户能开始任务，而不是只读品牌故事。
2. **诚实披露**：登录、积分、Early Access 限制写清楚；无真实评价则关闭 testimonial。
3. **SEO 一页一词**：每个页面一个主关键词；Title / H1 / 首段对齐同一意图。
4. **不破坏已购权益**：后续付费升级不得降级已有用户的访问权（版本2 起生效）。
