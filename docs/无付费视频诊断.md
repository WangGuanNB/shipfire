# 无付费视频诊断

仅 `AI_DIAGNOSTICS_EMAILS` 中的账号登录后，在视频工具底部看到「检查生成前流程」按钮。当前配置为 `banner520521@gmail.com`。普通账号看不到，接口也会拒绝访问；此权限不授予后台或积分管理能力。

## 怎么用

1. 正常上传所需照片、选择画质、确认使用许可，无需充值。
2. 点击唯一的「检查生成前流程」按钮。它使用当前表单，一次检查参数、预计扣分、模型配置、上传后的照片链接；参考视频方案还会自动复用正式生成的模板预检，检查视频读取、时长及所需音轨。纯图片方案不读取参考视频。
3. 查看逐项结果，必要时展开「查看检查详情与请求参数」定位问题。

不调用 Kie，不调用付费审核服务，不检查或扣减余额，不创建任务，不模拟成片，也不进行成片处理或视频存储写入。旧的独立模板/视频存储按钮及勾选项已移除；传旧操作给此专用接口也不会触发存储写入。

正式「生成视频」按钮仍会调用模型并按原规则扣积分，与测试按钮分开。

## 边界与配置

- 只检查生成前链路，不能保证 Kie 接受素材或生成成功；不覆盖生成后的视频下载、存储上传、播放、轮询和退款。
- 图片检查只验证服务器可读取以及响应类型/体积，不是完整图片解码、身份质量或供应商兼容性验证。
- 照片仍通过原上传流程真实存储，遵循原保留策略；读取素材仍可能产生少量流量费用。
- 服务端配置在 `wrangler.jsonc` 的 `AI_DIAGNOSTICS_EMAILS`，留空关闭。修改配置后本地需重启开发服务，生产需重新部署。不要改成 `NEXT_PUBLIC_*`。
- `/api/ai/diagnostics/operator` 每次独立验证已认证账号；前端 `can_test_ai` 只是显示提示，不能绕过权限。
