# 统一视频工作台：产品需求与验收

## 1. 目标

这是供不同 AI 网站复制使用的模板。站长发现新热词后，希望让 AI 主要通过修改配置、提示词、参考素材、示例和文案，快速上线对应玩法，不必每次重做工具表单、支付或任务流程。

最终提供一套统一的视频工作台，覆盖原有文字生成、普通图生视频和参考视频能力，并新增“用户人物照片＋后台场景／风格参考图＋预设提示词”的多图参考能力。

一个热梗对应一个“玩法”；一个玩法可以有一个或多个“生成方案”。用户可选择图片参考或视频参考等方案，方案可以采用不同模型、参数和积分价格。

统一的是使用体验与公共组件，不是把所有模型当成同一种接口。框架的登录、任务、积分、支付、存储仍然服务于其他 AI 工具，不能绑定视频或某个热梗。

## 2. 本期范围

必须实现：

- 统一工作台外壳、可配置输入区、示例／结果区、报价与生成操作。
- 原有自由文生视频和自由单图生成可继续使用。
- 一套玩法配置支持多个生成方案，不再要求用户先理解 Text / Image / Reference 的技术分类。
- 新增人物多图参考方案；后台可配置场景／风格参考图，也可不配置。
- 保留视频参考方案，同一玩法可同时提供图片方案和视频方案，各自报价。
- 复用任务、上传、历史记录、登录、积分和充值流程。
- 一份覆盖主要能力的开发／测试页配置，以及单玩法、双方案落地页配置示例。

本期不做：可视化运营后台、任意工作流编辑器、自动首尾帧合成、LoRA 训练、固定音乐合成、精确口型、自动剪辑，以及未经确认的用户任意参考视频上传。

“最全工具页”是能力完整的工作台，不是要求每次同时填满全部素材。开发／测试页也不得绕过登录、授权、审核或真实扣费提示。

## 3. 页面与交互

### 3.1 统一布局

保持现有左侧操作、右侧示例／结果的布局方向，复用现有主题变量和响应式样式，不修改首页其他模块。

左侧按当前方案展示：

- 玩法选择：站点仅绑定一个玩法时可不显示选择器。
- 方案选择：单方案直接进入；多方案显示名称、说明和对应积分。
- 用户照片槽位：由配置决定数量、角色、必填状态及上传说明。
- 预设参考素材：可展示只读预览或“已使用预设场景”等说明；不等于用户必须重新上传。
- 提示词区域：支持自由输入、预设指令＋用户补充、纯预设三种策略。
- 允许用户调整的画质、时长、比例、音频等参数。
- 真实的素材使用授权确认、费用和生成按钮。

右侧展示当前方案自己的效果示例与生成结果。切换示例只改变预览，不改变模型输入。不同方案不应无说明地共用一条效果明显不匹配的演示视频。

未选择的方案字段不参与提交。切换方案时更新素材要求、参数、示例和价格；不合法的旧值及时清理。生成中锁定当前方案，避免任务与表单错配；用户切换账号时清理上传和任务状态。

### 3.2 两类使用场景

- 综合工具页：允许选择多个生成方案，保留自由输入和适用参数，供通用用户使用或站长测试。
- 热词落地页：绑定一个玩法，只开放该玩法的一到多个方案；站长固定的素材、提示词和模型不需要用户配置。

两类页面复用同一套工作台，不复制业务代码。展示隐藏与后端禁用是不同概念：隐藏某项不代表服务端禁止使用，真正停用必须有服务端校验。

现有三个标签可由统一的方案选择交互替代，但不能因此丢失原功能。首页是否启用新版、开放哪些方案，由明确配置决定，不擅自隐藏其他模块或更改导航。

## 4. 素材及生成方案

### 4.1 图片参考方案（本期重点）

用户上传角色照片，站长在后台为该方案预设零张或多张场景／风格参考图，并配置提示词。

- 人物照片用于人物身份，预设图用于场景、风格或构图；必须说明每张图的用途。
- 后台参考图可复用，不要求每次生成前另做一张首帧。
- 总图片数量包含用户照片和后台参考图，受实际模型能力约束。
- 不能将人物参考图直接当成首帧，不默认传参考视频。
- 参考图不保证人物相似度、逐秒动作、口型或音乐一致性；素材中原人物可能干扰身份，需要实测筛选。

### 4.2 视频参考方案

用户上传角色照片，站长为该方案配置有权使用的参考视频及提示词。默认不向终端用户开放任意视频上传。

参考视频是独立生成素材，不从页面示例视频自动推导。若使用视频片段，站长配置时准备好片段并核实时长，不要求每个用户裁剪。

### 4.3 自由文字／普通图生视频

保留原有功能及语义，仍可作为统一工作台中的方案。普通单图生成与多张人物参考是不同能力，不强制合并请求方式。

用户照片、后台参考图、后台参考视频、示例视频必须有明确区分；“都生成视频”不代表所有素材可以随意组合。

## 5. 方案独立价格与参数

每个方案可独立配置模型、输出规格、允许修改项、积分规则及示例。照片数量、时长、画质、提示词和价格都不能在组件中写死。

- 用户切换方案或输出规格时，费用同步更新；未取得有效报价时不能提交。
- 服务端统一报价和扣费，客户端不能指定最终积分或绕过方案限制。
- 配置或价格变化后，旧页面应要求刷新／确认，不能静默按新高价扣费。
- 创建任务时保存输入、方案、模型和价格版本等必要快照，后续改配置不影响进行中的任务。
- 复用原有积分预占与结算。明确失败按规则释放；状态不明进入待核查，不擅自重试或返还后再生成。
- 不自动切换更贵模型，不用用户一次确认授权无限重试。

站内积分零售价和供应商成本是两套数值。不得承诺图片方案必然更便宜、视频方案必然更准或所有请求一分钟完成。

## 6. 音频、素材与用户预期

本期只保留实际支持的“关闭音频／模型生成音频”。固定背景音乐和口型同步后续单独开发，不把无效开关包装成已实现功能。

预设素材须经过站长检查并有使用权；用户应真实确认上传授权，沿用并验证内容审核。更换入口或不传参考视频不等于自动通过支付或内容审核。

示例应来自相应方案的真实输出。对外描述为可验证的同款玩法、场景或风格，不承诺逐帧复刻。没有性能测试时只展示真实任务状态，不编造确定的完成时间。

## 7. 以后如何追新词

已有能力范围内，新增玩法及方案配置，填写角色、预设素材、提示词、模型、规格、售价与示例，更新落地页文案，再测试上线。

同类玩法不应要求修改 React 表单核心、任务状态机、Stripe 或积分账户。若新需求涉及未支持的模型、音频处理或控制方式，则新增对应适配能力，不能承诺任何新梗都只改一句提示词。

## 8. 产品验收与交付

- 同一玩法至少能配置图片参考、视频参考两个方案并在工作台切换，分别显示真实费用。
- 图片方案能附加后台参考图，且无需参考视频即可提交；普通文字／单图生成继续可用。
- 角色数量、素材用途、提示词策略、参数和示例均按方案生效。
- 单玩法单方案、单玩法多方案、综合工具页都能由配置得到。
- 生成、播放／下载、余额刷新和历史记录正常；刷新或切换入口不造成重复付费提交。
- 验证空配置、缺素材、不支持参数、余额不足、明确失败、状态不明及重复请求。
- 旧任务和其他 AI 工具不受影响，移动端与主题样式不回归。
- 提供变更清单、配置示例、换梗操作说明、测试结果、待验证项及回退办法。

真实生成需先取得用户对样本数量和预算的确认。代码验收与效果验收分开：使用同一批已授权照片比较两条路线，记录实际费用、等待时间、人物相似度、场景一致性与“梗是否成立”。未经实测，不宣称效果或速度达标。
