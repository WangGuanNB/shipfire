# 工具内页克隆说明

> 模版站提供两个 **完整工具内页**，用作 hero 工具区的参考实现。  
> 上线新站时：**首页文案自己写**，hero 里的工具从内页样板复制。

---

## 两个参考内页

| 内页 | 路由 | JSON | hero 工具 |
|------|------|------|-----------|
| 图片样板 | `/image-generator/` | `src/i18n/pages/image-generator/{locale}.json` | `tools.primary.type: "image-generator"` |
| 视频样板 | `/video-generator/` | `src/i18n/pages/video-generator/{locale}.json` | `tools.primary.type: "video-generator"` |

页面结构相同：`LandingRenderer` + 模块列表（introduce、usage、feature、faq…）。

---

## 克隆新站时怎么做

### 1. 首页内容自己写

`src/i18n/pages/landing/{locale}.json` 里的：

- `metadata`（title、description、keywords）
- `hero` 的 **标题、描述、metrics**（营销文案）
- `introduce`、`usage`、`faq`、`cta` 等模块文案

按新站关键词与产品定位重写。

### 2. 从样板内页复制 hero 工具

打开 **图片** 或 **视频** 样板 JSON，复制到 `landing/{locale}.json`：

```text
hero          → 保留 variant: "tool"，文案可改，结构对齐样板
tools         → 整段复制（核心）
modules 里 hero 项 → 确保有 tool: "primary"
```

**图片站复制示例：**

```json
"tools": {
  "primary": {
    "type": "image-generator",
    "config": {
      "promptLabel": "...",
      "buttonText": "Generate image",
      ...
    }
  }
}
```

**视频站复制示例：**

```json
"tools": {
  "primary": {
    "type": "video-generator"
  }
}
```

视频工具 UI 在 `src/components/ai/video-tool.tsx`，注册在 `src/components/landing/tools.tsx` 的 `landingToolRegistry`。

### 3. 不必复制的

- 样板内页的 introduce / faq 全文（除非你想整段参考 SEO 结构）
- `/tools/` 路由（legacy 简页，克隆站可忽略）
- `AI_ENABLED_TOOLS`（本地/模版默认两个工具都可用；克隆站按需保留内页路由即可）

## 相关代码（一般不用改）

| 文件 | 作用 |
|------|------|
| `src/components/landing/tools.tsx` | hero 工具注册表（image / video） |
| `src/components/landing/tools/image-generator.tsx` | 图片 hero 插槽 |
| `src/components/ai/video-tool.tsx` | 视频 hero 插槽 |
| `src/config/ai.ts` | 模型与积分报价（改 env 或此文件） |
| 积分 / 支付 / 任务 API | 通用底座，所有工具共用 |

## 本地预览

```bash
pnpm dev
```

- 图片样板：https://你的域名/image-generator/
- 视频样板：https://你的域名/video-generator/

测试视频时请保持页面打开直至任务完成（本地未配 maintenance cron 时）。

## 快速检查清单

- [ ] `landing` 的 `tools.primary.type` 与产品一致（image / video）
- [ ] `modules` 里 hero 带 `"tool": "primary"`
- [ ] `KIE_API_KEY` 已配置
- [ ] 图片：`AI_CHAT_CREDIT_COST`；视频：时长×分辨率影响积分
- [ ] 登录后可提交任务
